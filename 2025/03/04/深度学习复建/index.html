动手学深度学习（电子版教材）

安装pytorch

用的nvidia的显卡，驱动和cuda好像都装上了nvidia-smi查看cuda版本、

显卡利用率

直接pytorch官网看安装命令

pip3 install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu126

不指定源会安装cpu版本，使用gpu时会报错

libcudart functions unavailable. It looks like you have a broken build

概念

训练数据集：没什么好说的，拿来训练模型的

验证数据集：个人理解，用来调超参数的

测试数据集：个人理解，用来测试训练结束后的模型的效果（只用一次）

L1范数：所有元素绝对值的和（范数：norm）

L2范数：向量的模

k折交叉验证

听过没用过

全连接层

fully connected layer，也叫仿射层(affine layer)，线性变化 $y = wx$

拿张以前画的图。多个组合加上激活函数就是多层感知机MLP（Multilayer Perceptron）

激活函数

引入非线性，没有激活函数的话，多个全连接层，仍是线性变换，表现能力弱

  • sigmoid

  • tanh

  • relu

relu计算简单，可以减缓梯度消失（其他两个在输入较大时趋于平缓）

过拟合和欠拟合

overfitting，underfitting

过拟合：同一个训练集训练次数过多，模型容量较大，数据较为简单

欠拟合：模型容量较低，数据较为复杂

权重衰退

λ大于0，限制权重的L2范数在一定范围内

dropout

在层间加噪音，有说法认为是一种正则（控制模型复杂度）

以p的概率丢弃部分输入，未被丢弃的输入除以1-p，令输入的期望不变。也可看为丢弃了部分节点（神经元）

训练时使用，推理中不使用

数值稳定性

梯度爆炸、梯度消失

让训练更稳定：乘法变加法（resnet），归一化normalization（均值为0，方差不变。概率统计中，减去均值，除以标准差/方差），梯度裁剪gradient clipping

卷积层

平移不变性，个人理解，一张图片中的一个物体，不管怎么平移，不管在照片中的位置是右上角还是左下角，仍是同一个物体

局部性，个人理解，位置相近的元素相关性更高，离得远的图像，之间可能没什么关联

如今一张普通的图片像素数量很多，只用全连接层会导致参数数量过多。好像还听过一种说法，全连接层运算前要把二维图片拉成一维向量，y轴上元素之间的相对位置信息被抹去了，也就是不怎么考虑二维空间上的相对位置，卷积层计算则利用到了这个位置信息（图像用二维卷积，视频可能要三维卷积）

具体计算很简单，拿张以前画的图，省去了多通道相加以及偏置（kernel实际上还有输入输出通道数，共4个维度）。一维卷积说的抽象点是左边的乘右边的再积分，二维因为对称性结果相同，所以是相同位置相乘（交叉相关）。还有两个超参数是填充（图像周围补0，调节输出形状）和步幅（横竖平移的步幅，调大可加速形状变小）

1x1卷积层，相当于全连接层，可改变通道数

计算复杂度，$输入通道数 * 输出通道数 * 输入图像长度 * 输入图像宽度 * 输出图像宽度 * 输出图像宽度$，FLOP

有个说法，同样计算量下，2个3x3卷积比1个5x5效果更好，2个3x3视野更广

池化层

缓解卷积层对位置的敏感性，窗口大小、填充、步幅

全局平均池化层

经典卷积神经网络模型

经典模型：LeNet、AlexNet、VGG、NiN、GoogLeNet、ResNet

数据集：MNIST、CIFAR

批量归一化

计算小批量的均值和方差（计算值，全连接层特征维、卷积层通道维），然后归一化，再进行偏移和缩放（参数）

有论文认为是增加了噪声，没必要和丢弃法一起使用

加速收敛，不改变模型精度

硬件

CPU，central processing unit，中央处理器

GPU，graphics processing unit，图形处理器

ASIC，application specific integrated circuit，专用集成电路

FPGA，field programmable gate array，现场可编程门阵列

多卡并行

数据并行、模型并行、通道并行

DDP,distributed data parallel，分布式数据并行

gpu通信：pcie、nvlink、nvswitch、RDMA（remote direct memory access）/infiniband

数据增强

从原始数据集得到更多样本（变形，加入一些干扰），反转（上下、左右）、切割（高宽比、随机大小、随机位置）、改变色调/饱和度/明亮度、旋转等等（photoshop能做的）

微调

fine-tuning，网上说是迁移学习（transfer learning）的一种具体做法

从预训练的模型开始训练，速度更快，精度更高。更强的正则，使用更小的学习率，更少的数据迭代。源数据集远复杂于目标数据效果更好

重用分类器（softmax层）权重。固定一些层（底层），算是更强的正则，从layer 1到output layer（从底层到高层），特征抽取到分类，低层次特征更加通用，高层次和数据集相关，分类器重新训练
